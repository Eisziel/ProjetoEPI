Erros comuns & soluções

Antes de chamar suporte, dá uma olhada se o seu problema é um desses aqui 👇

Possíveis causas:
  • Usuário ou senha do Usuário do Sistema digitados incorretamente;
  • Usuário marcado como inativo no cadastro;
  • Tentando usar o login administrativo do Django em vez do login do sistema.
Como resolver:
  • Verifique se está usando o menu Entrar (login do sistema) ou Conta Administrativa (admin Django);
  • Confirme usuário e senha exatamente como foram cadastrados;
  • Acesse o admin Django, abra Usuário do Sistema e confira se o campo Ativo está marcado.

Possíveis causas:
  • Você não está logado como usuário do sistema;
  • A rota exige autenticação e está redirecionando para login.
Como resolver:
  • Faça login pelo menu Entrar antes de acessar Cadastro de Colaboradores;
  • Confirme se a URL que você acessou é /colaboradores/novo/ (menu lateral) e não outra rota antiga;
  • Se estiver usando outro navegador, confira se a sessão não expirou.

Possíveis causas:
  • Formulário sem classes CSS do Bootstrap aplicadas;
  • Algum campo não foi incluído no template.
Como resolver:
  • Verifique no template se os campos estão sendo exibidos um a um (ex.: {{ form.nome }}, {{ form.email }});
  • Confira se o forms.py está definindo corretamente os widgets com class="form-control";
  • Veja se o template está estendendo page_app/global/index.html, para manter o mesmo layout do site.

Possíveis causas:
  • Colaborador ou equipamento ainda não cadastrados;
  • Datas inválidas (por exemplo, devolução antes da entrega);
  • Algum campo obrigatório foi deixado em branco.
Como resolver:
  • Cadastre primeiro Colaboradores e Equipamentos antes de usar o menu Controle de EPI;
  • Confira se a data de entrega é anterior à data de devolução;
  • Veja se todos os campos marcados como obrigatórios estão preenchidos.

Possíveis causas:
  • Nome da rota (URL name) alterado em urls.py mas não atualizado no template;
  • Caminho digitado manualmente incorreto.
Como resolver:
  • No template, confira se o nome usado na tag url (por exemplo 'listar_colaboradores') é exatamente o mesmo definido em name= dentro do urls.py;
  • Evite digitar a URL na barra do navegador, use sempre os links do menu lateral/topo;
  • Se mudou alguma URL recentemente, revise todos os templates que usam essa rota.
